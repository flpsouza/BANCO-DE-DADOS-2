- A importância da coleta de dados e informações para uma empresa:
Uma boa coleta e um bom tratamento de dados para uma empresa são de grande importância, não só sobre os lucros, mas para a estrutura de uma empresa. Com essas informações, a empresa poderá ver onde ela possui falhas dentro de seus processos. Usando como exemplo o filme O Homem que Mudou o Jogo, do diretor Bennett Miller, ele mostra como ter uma base de dados dos funcionários (ou jogadores, no contexto do filme) pode mudar o rumo de uma empresa (ou time). No filme, o gerente geral de um time de beisebol tem um orçamento apertado, então ele tem que tomar as melhores decisões para contratar jogadores com esse baixo orçamento. No filme, ele conhece um rapaz que é formado em contabilidade e que possui um programa com uma base de dados dos jogadores. Com essa análise de dados, o gerente faz contratações para o elenco que fazem com que o time, que passava por uma baixa, comece a ganhar. Mesmo que os outros líderes do time questionem as escolhas do gerente, ele mostrou resultados vendo de uma forma analítica seus jogadores. O filme mostra como ter uma coleta de dados e um bom tratamento desses dados podem mostrar o que a empresa precisa melhorar; dessa forma, ela pode se estruturar melhor e evitar gastos e perdas mais para frente.
